# SLURM Batch Scripts for HPC

## Quick Start

### Step 1: Generate batch submission script
```bash
sbatch batch_submissions/generate_submissions.sh
```

This creates `batch_submissions/batch_submit_all.sh` with all submission commands.

### Step 2: Run all submissions
```bash
sbatch batch_submissions/batch_submit_all.sh
```

This runs all model evaluations and generates submission CSVs.

### Step 3: Extract accuracies
```bash
sbatch batch_submissions/extract_accuracies.sh
```

This parses the logs and creates `accuracy_summary.csv`.

### Step 4: View results
```bash
cat batch_submissions/accuracy_summary.csv
```

---

## Scripts Overview

1. **`generate_submissions.sh`** - Generates the batch submission script
   - Runs: `generate_batch_submissions.py`
   - Output: `batch_submissions/batch_submit_all.sh`
   - Time: ~1 minute (CPU only)

2. **`batch_submit_all.sh`** - Runs all model submissions
   - Generated by step 1
   - Runs: All `generate_submission*.py` scripts
   - Output: Submission CSVs + logs with accuracies
   - Time: ~24 hours (GPU required)

3. **`extract_accuracies.sh`** - Extracts accuracy from logs
   - Runs: `extract_accuracies.py`
   - Output: `accuracy_summary.csv`
   - Time: ~1 minute (CPU only)

---

## Complete Workflow

```bash
# 1. Generate submission script
sbatch batch_submissions/generate_submissions.sh

# 2. Wait for it to finish, then check output
squeue -u bm3772
cat batch_submissions/generate_submissions_*.out

# 3. Submit all evaluations
sbatch batch_submissions/batch_submit_all.sh

# 4. Wait for all submissions to finish (check with squeue)
squeue -u bm3772

# 5. Extract accuracies
sbatch batch_submissions/extract_accuracies.sh

# 6. View results
cat batch_submissions/accuracy_summary.csv
```

## Check Job Status

```bash
# See your jobs

tail -f batch_submissions/generate_submissions_*.out

tail -f batch_submissions/extract_accuracies_*.out
```

## Notes

- All scripts use `conda activate dino_new` - make sure this environment exists
- GPU jobs use `partition=a100_short` (adjust if needed)
- CPU jobs use `partition=cpu` (adjust if needed)
- Logs are saved with job ID: `*_%j.out` and `*_%j.err`
